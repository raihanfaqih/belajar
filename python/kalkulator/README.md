# *Tujuan
dibuat untuk melatih dasar-dasar pemrograman, kalkultor adalah program yang cocok untuk pemula untuk bisa lanjut ke tahap selanjutnya

# *Program 
kalkulator ini dilengkapi dengan beberapa fungi, fungsi untuk menghitung angka serta menyimpan nilainya yang akan diproses pada tahap selanjutnya, lalu input untuk menanyakan pertanyaan kepada user, dan juga akan ada perulangan pada tahap selanjutnya
